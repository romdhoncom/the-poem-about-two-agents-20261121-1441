# the-poem-about-two-agents-20261121-1441

A short poem about agency — the power to choose and to act — and specifically about two agents agreeing on one plan: the agency that passes between them when one says yes to the other's plan.

## Run it

```sh
python3 main.py
```

It writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
